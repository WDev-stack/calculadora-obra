# Calculadora de Revestimentos

Aplicação web para cálculo de área e estimativa de custo de materiais para obras.

## Tecnologias
- React.js
- Vite
- Tailwind CSS

## Instalação e Execução
1. Instalar dependências:
   npm install

2. Iniciar servidor de desenvolvimento:
   npm run dev

## Funcionalidades
- Seleção de materiais (Cerâmica, Porcelanato, Mármore)
- Cálculo automático de m²
- Formatação de valores em BRL (moeda brasileira)
